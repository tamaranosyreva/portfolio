# Тамара Носырева — портфолио

Статический сайт без сборки: главная `index.html` и страницы кейсов в `cases/`.
Стили — `assets/css/style.css`, выравнивание по сетке 24px — `assets/js/main.js`.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в него содержимое этой папки (вместе с файлом `.nojekyll`).
2. Settings → Pages → Build and deployment: Source — «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
